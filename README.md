# Lego-waste-classification-and-cleaner-bot-using-machine-vision
The main goal of the project was to create a cleaner robot that classifies waste for recycling. The robot is deployed in a controlled environment and begins to find metal, plastic, and paper waste to return to their respective bins 


**Objective** 

Two-wheeled bot that uses camera to locate trash. determines said trashes classification using machine learning and a vision camera. Pick up the trash, and return it to either metal, plastic, or Paper Bin.

- Lego Spike prime Kit (Hub, motors, distance sensors, beams, and wheels)
- OpenMV camera
- Antons openMv-spike prime breakout board 

**Software Used** 
- pybricks
- Openmv Ide
- Edge impulse for waste classification training
- Multiple pictures of paper, plastic and metal
